# Blueprint True Cost

A [Satisfactory](https://www.satisfactorygame.com/) mod that recalculates a blueprint's cost from its actual buildings.

Blueprints store their cost in the file when saved, so a downloaded blueprint keeps charging its author's prices even when a mod like Free Architecture has made those buildings free. This mod recalculates the cost from the buildings inside and your current recipes when you select the blueprint.

Built with [SML](https://ficsit.app/mod/SML) (Satisfactory Mod Loader).

## Installation

Install through the Satisfactory Mod Manager, or from [ficsit.app](https://ficsit.app).

## Building

Clone into `Mods/GameFeatures` of an SML 3.12.0 starter project and package with Alpakit.
